# 🏫 Campus Convenience

A simple and practical web application designed for hostel students to easily order food and essentials from nearby local stores.

## 🚀 Features

- 🏪 View multiple nearby stores (Fruit Shop, Fast Food, Dairy, etc.)
- 📋 Browse store menus with prices
- 📱 Mobile-friendly UI (Zomato-style layout)
- 💬 One-click ordering via WhatsApp
- 🧾 Pre-filled "kitchen slip" format for vendors

## 🛠️ Tech Stack

- HTML
- CSS (Grid & Responsive Design)
- JavaScript
- WhatsApp Click-to-Chat API

## 💡 How It Works

1. User selects a store from the homepage  
2. Views available products  
3. Enters quantity and room number  
4. Clicks "Order"  
5. WhatsApp opens with a pre-filled order message  
6. Vendor receives the order instantly  

## 🔮 Future Improvements

- 🛒 Add to Cart system
- 💰 Total bill calculation
- 🔐 Vendor/Admin dashboard
- 📦 Order tracking system
- 💳 Online payments (UPI)

## 🎯 Goal

To simplify campus ordering by connecting students with local vendors using a lightweight and accessible platform.
